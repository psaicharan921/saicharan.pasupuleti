## 🎯 Overview

This repository houses my personal tech portfolio – a sleek, animated, and responsive site built with:

- **React + TypeScript**
- **Tailwind CSS**
- **Framer Motion**
- **Vite**

Designed to showcase my expertise in **Cloud**, **DevOps**, **IoT**, and **Cybersecurity** through interactive visuals, live demos, and featured project breakdowns.
